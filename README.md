### 一键打开本地页面

双击项目根目录的 `start_teacher_copilot.bat`。脚本会检查 8765 端口：服务未运行时启动本地页面，服务已运行时直接打开现有页面，不会重复启动。也可以在 PowerShell 中运行：

```powershell

```

```powershell
py -m pip install -r requirements.txt
py lesson_generator.py --unit 1 --material-type lecture
```

按提示填写学科、年级、主题、课时和学习目标。Methods 示例主题：
`calling methods parameters return values`。

检查项定义在 `teacher_copilot/profiles.py`，属于本课教学清单，不是 AP CSA 全课程覆盖表。

- `exercise_report.md`：四层难度的教师审阅报告，含 5 道原创练习和 1 道独立离堂题、答案、推理、干扰项解释与评分。
- `exercise_plan.json`：上述练习的结构化数据和参考课堂安排。
- `questions.json`：统一题目档案，逐题记录内容、来源、版本、审核、锁定和修改历史。

练习由 `teacher_copilot/exercises.py` 中预先编写的固定本课题库提供，离线运行不会每次自动创作新题。
所有题均标记为原创；最后两题参照官方选择题形式，不是 AP 真题，也没有经过学生试测来校准难度。
题目从基础识别、单步应用、综合跟踪递进到嵌套调用和需求匹配；额外的离堂题用于独立达标检查。
Q4 使用整数除法，需要先教或复习，不能把未教知识当成提高难度的方式。
报告的参考课堂安排合计 45 分钟；若指定其他课时，会明确提示重新安排。
联网教案提示词也加入同样的分层要求，但离线题库不是模型生成的教案，也不保证模型逐字采用这些题。
算术和选项唯一性已通过离线测试；当前未用 Java 编译器验证。

三种状态分别表示未找到候选、候选已纳入提示词、候选因片段数或长度限制未纳入。
命中只是词汇线索，不保证知识点完整、题目难度适合或例题正确；报告勾选项供教师人工使用，
当前不会把 Markdown 勾选自动同步回 JSON，也不会自动把结果标为“已覆盖”。
特别检查：实参数量／顺序／类型是否分别具备证据，错误示例是否属于调用而非编写方法，
练习是否无需额外知识且有答案。

该模式目前只支持本地关键词检索；只有明确加 `--online` 才调用生成 API。
候选未进入提示词时会在生成指令中注明，防止把未提供的内容当成教材依据。

每次运行在 `outputs/` 下生成一个独立文件夹：

- `retrieval_report.md`：完整教材片段、PDF 页码、分数、异常提醒和人工检查项。先查看这个文件。
- `prompt.md`：包含教材内容的完整教案提示词。没有检索结果时不会生成。
- `metadata.json`：输入、筛选条件、来源和执行状态。
- `lesson.md`：仅联网生成成功时出现。
- `lesson_partial.md`：联网返回未完成或空结果时使用，不会自动重试。

默认最多 4 个合并片段，正文预算 4800 字符，不是 4800 tokens。
程序保留完整片段，不能放入预算的片段会跳过，因此可能少于 4 个。
需要更多上下文时可使用 `--context-chars 7000`；联网时会增加输入量。
页码从 PDF 第一页开始计数，不一定等于纸面印刷页码。

## 缓存与文本质量

`.cache/pdf_text/` 保存 PDF 原始提取文本，根据文件内容及 pypdf 版本复用；文件变化时重新提取。
清理只去掉少量已确认的整行页眉，不删除代码字符。异常字符保留并在报告中提示。
按完整行切分，尽量不拆开花括号包围的代码块，并合并同页相邻上下文。
这不是 Java 语法解析器；跨页代码、PDF 阅读顺序及 OCR 问题仍需要人工对照原文。
`embeddings_cache_v3.json` 是联网语义检索缓存，每次成功请求后保存。
保留分批处理功能，默认每批 50 段，可用 `--embedding-batch-size` 调整。
缓存按文本内容匹配；材料排序改变不会串用向量。每批核对返回数量、索引、数值和维度后才保存。
失败后保留之前成功的批次；失败批次可能已被服务方计费，重新运行不保证免除该批费用。
旧版本无配置标记的缓存不会自动导入，也不会删除。

## 题目数据规则（格式版本 1）

`questions.json` 顶层包含 `schema_version` 和 `questions`。每题包含：

- `content`：完整原题，包括题干、代码、层级、时间、目标、答案、解析、选项、评分和教师处理。
- `provenance`：原创 / 教材原题 / 教材改编；教材来源需有文件名与 PDF 页码，改编需说明改动。
- `revision`、`content_hash`、`history`：当前修订号、内容摘要和历史记录。
- `locked`：锁定题不能修改内容，需显式解锁。
- `validation`：教师审核、技术审核、难度试测三个独立状态；初始为待审核。

通过 `questions.revise` 修改内容会保留旧内容并重置审核状态。
`questions.review` 记录审核人及依据；`questions.set_locked` 记录锁定与解锁。
这些接口已接入本地教师审阅页面。格式校验不代表答案正确或达到真实考试难度。
每次离线生成建立新的独立档案；审阅页面在原报告目录保存 questions_review.json，保留原始题目。

## 生成课堂练习（新版页面）

在项目目录运行：

```powershell
py start_review.py
```

打开 http://127.0.0.1:8765 。仅在本机运行，不需要租服务器或 API Key。
重启电脑后需重新运行启动命令；按 Ctrl+C 停止。端口被占用可使用 `--port 8767`。

### 老师的操作顺序

1. 选择使用方式：快速练习，或正式试卷。
2. 选择课题；当前题库覆盖 4 个单元、21 个独立课题和 275 道题，也可在正式试卷中选择“全课程混合组卷”。
3. 勾选当前课题对应的考查内容。切换课题会更新选项并清空旧勾选。
4. 快速练习选择基础、巩固或考试，并设置 10/20 分钟；正式试卷选择混合或单一难度，并设置考试时间、题量、总分和题型。
5. 检查整套题目；需要时展开答案、换题、修改或锁定已审核题目。
6. 导出学生版（不含答案）或教师版（含答案、解析、评分和正式试卷分值），格式为 Word。

### 当前边界

- “本地题库（免费）”使用已审核的本地题目；“题库优先，不足时用 AI 补题”会先用本地题目，仅在目标时长不足时调用免费模型补齐剩余时长。
- “AI 实时生成”默认关闭。启用后由本机后端调用 Responses API，每次生成或 AI 换题最多发起一次请求；题目会先经过字段、标签、重复、时长和覆盖检查，再进入教师审核，答案不会自动视为已验证。
- 正式试卷支持本地题库、全课程混合组卷和 AI 实时生成；支持题量、总分、题型和考试时长，AI 结果会检查题型、分值、覆盖和总时长。
- 启用实时生成前，在服务器进程环境中设置 `TEACHER_COPILOT_ENABLE_AI=1` 和 `OPENAI_API_KEY`；`OPENAI_MODEL` 可选，默认使用 `gpt-6-luna`。密钥只放在后端环境变量，不写进浏览器或题目文件；页面显示当天请求次数和剩余额度，默认每日最多 10 次请求。
- 免费补题可设置 `TEACHER_COPILOT_ENABLE_AI=1`、`OPENROUTER_API_KEY` 和 `OPENROUTER_MODEL=openrouter/free`；密钥只放在后端环境变量，免费模型的额度和可用性由服务商限制。
- 按考查范围和难度筛选，在目标时间内优先满足内容覆盖和难度梯度，不重复题目凑时长。
- 无符合条件的题目时明确报错；覆盖不足、时间不足或修改后超时会提示。
- 修改保存在独立的 questions_review.json 中，原始题目保留；修改后审核状态重置。
- “打开之前的练习”可找回已保存内容；刷新页面会回到设置入口。
- 每次导出保存在本次练习目录下新的 reviewed_... 文件夹中，同时触发浏览器下载。
- 审核与锁定的底层接口保留，但不占据新版主要操作流程；已锁定题目修改前需解锁。

自动测试：85 项通过。浏览器已验证快速练习、正式试卷入口、全课程混合组选项、题库关键词搜索、按需编辑、保存、锁定、时间重算、学生版导出、练习库管理、质量检查、双语解析入口，以及 AI 实时生成状态。
新增核心逻辑位于 teacher_copilot/worksheets.py，测试位于 test_worksheets.py。

讲解建议已改名为“学生答错时的讲解建议”，在答案及编辑区默认折叠。可以不修改；编辑时留空会保留原建议。学生版不包含该建议。
